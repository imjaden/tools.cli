LockScreen 插件

轻量级锁屏插件，密码为当前日期的mmddHH 格式（月/日/小时）

使用说明

1. 引入插件

在HTML中引入插件文件和依赖资源：

<script src="/assets/js/tailwindcss@3.4.17.js"></script>
<link href="/assets/css/font-awesome@4.7.0.min.css" rel="stylesheet">

<!-- 引入锁屏插件 -->
<script src="/lock-screen-plugin@1.4.js"></script>
<!-- 今日诗词数据（供悬浮面板展示，file:// 可用；不引入则 todayInfo 为空、面板不渲染） -->
<script src="/today-poetry.json.js"></script>

2. 基本用法

插件会自动初始化，您可以通过全局实例控制锁屏功能：

// 锁定屏幕
window.lockScreenInstance.lock();

// 检查当前是否处于锁定状态
console.log(window.lockScreenInstance.getIsLocked()); // true/false

3. 自定义配置

您可以通过自定义配置初始化插件：

// 销毁默认实例（如果已初始化）
if (window.lockScreenInstance) {
  delete window.lockScreenInstance;
}

// 自定义配置初始化
window.lockScreenInstance = new LockScreen({
  lockDuration: 15 * 60 * 1000, // 15分钟自动锁定
  pinLength: 6, // PIN码长度
  title: '请输入密码解锁', // 自定义标题
  // 今日信息（农历/节气 + 推荐诗词），传 null 则诗词面板不渲染
  todayInfo: {
    dateLine: '丙午年（马）七月十七 · 白露',
    poemTitle: '月夜忆舍弟',
    poemAuthor: '杜甫',
    poemParagraphs: ['戍鼓断人行，秋边一雁声。', '露从今夜白，月是故乡明。']
  },
  // 右上角悬浮诗词面板：enabled 开关、defaultOpen 是否默认展开
  poetryPanel: { enabled: true, defaultOpen: true }
});

4. 锁屏按钮示例代码

创建一个锁屏按钮的完整代码：

<!-- 按钮HTML -->
<button id="lock-btn" class="bg-primary text-white px-6 py-3 rounded-lg hover:bg-primary/90 transition-colors">
  <i class="fa fa-lock mr-2"></i> 锁定屏幕
</button>

<!-- 按钮事件绑定 -->
<script>
  document.getElementById('lock-btn').addEventListener('click', function() {
    // 调用锁屏方法
    window.lockScreenInstance.lock();
  });
</script>

5. 自定义回调函数

您可以为锁定和解锁操作添加自定义回调函数，用于执行额外逻辑：

// 方法1: 初始化时配置默认回调函数
if (window.lockScreenInstance) {
  delete window.lockScreenInstance;
}

window.lockScreenInstance = new LockScreen({
  lockDuration: 15 * 60 * 1000,
  pinLength: 6,
  title: '请输入密码解锁',
  onLock: function() {
    console.log('屏幕已锁定（默认回调）');
  },
  onUnlock: function() {
    console.log('屏幕已解锁（默认回调）');
    // 可以在这里添加解锁后的操作，如恢复数据等
  }
});

// 方法2: 调用时传递回调函数
// 锁定屏幕时添加回调
document.getElementById('lock-btn').addEventListener('click', function() {
  window.lockScreenInstance.lock(function() {
    console.log('屏幕已锁定');
    // 可以在这里添加锁定后的额外操作，如发送统计信息等
  });
});

// 解锁成功回调：仅支持 onUnlock 配置项或 unlock(cb) 方法参数两种方式
// （插件不派发自定义 DOM 事件，监听 'lockscreen-unlock' 不会触发）

回调函数可以用于执行各种操作，如记录日志、发送通知、更新UI状态等。 当同时设置了初始化配置中的回调和方法调用时的回调，会优先执行方法调用时传递的回调。

6. 功能特点

  • 支持屏幕自动锁定（默认30分钟无操作）
  • 支持物理键盘输入数字和删除
  • 支持屏幕键盘输入
  • 自动生成基于当前时间的PIN码（mmddHH格式）
  • 解锁状态本地存储，页面刷新后保持
  • 右上角悬浮「今日诗词」面板：展示完整诗词，标题栏可折叠、默认展开
  • 诗词面板层级高于锁屏层，锁屏/解锁状态均可见，位于右上角不遮挡居中 PIN 键盘
  • 成套主题色：内置 4 套预设（紫蓝星辰 / 深蓝夜空 / 墨绿 / 暖橙），锁屏界面左上角下拉切换，刷新后保持
  • 响应式设计，适配各种屏幕尺寸

7. 主题切换

锁屏界面散落的颜色统一抽取为 CSS 变量，内置 4 套成套预设主题，可通过配置档指定默认主题，并在锁屏界面通过左上角下拉实时切换：

window.lockScreenInstance = new LockScreen({
  // ... 其它配置 ...
  // 默认主题名：violet-star / midnight-blue / forest-green / sunset-amber
  defaultTheme: 'midnight-blue',
  // 锁屏界面主题下拉开关（默认 true）
  themeSwitcher: { enabled: true },
  // 主题切换回调
  onThemeChange: function(name) {
    console.log('当前主题：' + name);
  },
  // 自定义主题（扩展预设，需提供 CSS 变量集）
  themes: {
    'ocean-cyan': {
      label: '青蓝海洋',
      vars: {
        '--lock-bg-gradient': 'linear-gradient(135deg,#0f2027 0%,#203a43 50%,#2c5364 100%)',
        '--lock-accent': '#22d3ee',
        '--lock-pin-filled-bg': 'rgba(34,211,238,0.18)',
        '--lock-panel-header-gradient': 'linear-gradient(135deg,#0f2027 0%,#2c5364 100%)'
      }
    }
  }
});

主题优先级：localStorage.lockScreenTheme（用户选择） > defaultTheme（配置档） > 紫蓝星辰（内置默认）。 更改主题后即时生效并写入 localStorage，刷新后保持。主题下拉位于锁屏界面左上角，避开右上角诗词面板。
